# EduGenie – User Manual

1. Open the app in your browser (default: http://127.0.0.1:8000).
2. **Choose a task** from the dropdown: Ask a Question, Explain a Topic, Generate Quiz, Summarize Text, or Learning Path.
3. Type your input in the box, or click **Load Example**.
4. Click the submit button. Wait for the status message to finish.
5. Read the result. Use **Copy** to copy it.
6. For quizzes, click an option to see whether it is correct.

| Task | What to type |
|---|---|
| Ask a Question | A question, e.g. "What is RAM?" |
| Explain a Topic | A topic name, e.g. "Pythagoras theorem" |
| Generate Quiz | A paragraph of study material |
| Summarize Text | A long passage |
| Learning Path | A subject, e.g. "Python programming" |

**Tips:** Keep input under 12,000 characters. Verify important facts with your textbook.

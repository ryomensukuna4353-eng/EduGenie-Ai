# Phase 8 – Project Demonstration

## Demo Script (about 5 minutes)
1. **Introduce** the problem and EduGenie (30 s).
2. **Start the server:** `uvicorn main:app --reload`, open the browser.
3. **Ask a Question:** "What is the difference between RAM and ROM?"
4. **Explain a Topic:** "Pythagoras theorem".
5. **Generate Quiz:** use the photosynthesis example; click answers to show feedback.
6. **Summarize Text:** use the AI example paragraph.
7. **Learning Path:** "Python programming".
8. **Show robustness:** submit empty input; show `/health` and `/docs`.
9. **Show tests:** run `pytest` in the testing folder.
10. **Close:** limitations and future scope.
